## 📌 Sobre o Projeto

Este projeto demonstra na prática como construir, orquestrar e integrar **Agentes Inteligentes** utilizando o ecossistema de Inteligência Artificial do Google.

```
┌─────────────────┐       ┌──────────────────┐       ┌─────────────────┐
│                 │       │                  │       │                 │
│   User Input    │ ───►  │   AI Agent (IA)  │ ───►  │  Tools & APIs   │
│                 │       │                  │       │                 │
└─────────────────┘       └──────────────────┘       └─────────────────┘
```

---

## 🎯 Principais Objetivos

* 🧠 **Engenharia de Prompts** para agentes autônomos.
* 🛠️ **Tool Use & Function Calling** com modelos Gemini.
* 🔄 **Orquestração de Fluxos** e tomada de decisão.
* 🚀 **Aplicações Práticas** e casos de uso reais.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python
* **Modelos:** Google Gemini AI
* **Frameworks & SDKs:** `google-generativeai` / Vertex AI SDK

---

## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/DaviP-Conceicao/MasterClassAgentsGoogle.git
   cd MasterClassAgentsGoogle
   ```

2. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure sua Chave de API:**
   ```bash
   export GEMINI_API_KEY="SUA_CHAVE_AQUI"
   ```

4. **Execute os scripts:**
   ```bash
   python main.py
   ```
